## Batas dan pekerjaan lanjutan

- Tidak mengklaim atomic locking lintas proses/tab: localStorage tidak menyediakan transaksi compare-and-swap. Penanganan di atas mencegah konflik yang teramati dan stale writes sederhana; penyuntingan benar-benar simultan masih memerlukan Web Locks/IndexedDB. Ekspor sebelum memilih versi konflik.
- Belum ada uji semua browser/perangkat, full WCAG audit, verifikasi splash/install pada perangkat fisik, atau pengujian rollout pembaruan dua deployment service worker.
- Semua 36 soal asli dipertahankan dan lolos validasi struktural otomatis. Validitas struktur bukan validitas medis; jumlah/kedalaman konten dan validasi dokter masih menjadi batas tahap pertama.
- Tidak ada skema entity baru yang memerlukan upgrade versi state; parser menerima raw state v1 dan format backup envelope v1. Versi masa depan ditolak tanpa menghapus data lama. Tidak dibuat migrasi spekulatif untuk versi yang tidak pernah diterbitkan.
- Verifikasi Vercel live dan publikasi snapshot lingkungan memerlukan akses/aksi produk terkait. GitHub API masih diblokir oleh kebijakan egress instance ini; Git push dan aplikasi lokal tidak bergantung pada akses tersebut.
